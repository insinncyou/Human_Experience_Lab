# Research Notes

Human Experience Labの訓練から得た、再利用可能な観察・仮説・判断・原則を保存します。

## File naming

`YYYY-MM-DD-short-topic.md`

例:

- `2026-07-18-coffee-shop-focus.md`
- `2026-07-25-bank-transfer-confirmation.md`

## 保存するもの

- 後から検証・反論できる具体的な観察
- 証拠の状態が明記された仮説
- 意思決定のトレードオフ
- 適用条件を持つDesign Principle
- 自分の判断基準が変わった記録

## 保存しないもの

- 会話全文の無加工コピー
- 根拠のない心理ラベル
- スクリーンショットだけの収集
- 文脈のない「ベストプラクティス」

新規ノートには `templates/RESEARCH_NOTE_TEMPLATE.md` を使用してください。
